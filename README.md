# CODTECH Java Internship Projects

This repository contains all the tasks completed during my Java Internship at CODTECH.  
The projects are developed using Java and demonstrate concepts such as File Handling, REST API Integration, Socket Programming, Multithreading, and Recommendation Systems.

---

# Internship Tasks

## Task 1 - File Handling Utility
A menu-driven Java application that performs file operations such as:
- Create File
- Read File
- Write File
- Append Data
- Modify Existing Content
- Clear File Content

### Technologies Used
- Java
- File Handling
- BufferedReader
- FileWriter

---

## Task 2 - REST API Client
A Java application that consumes a public REST API and displays structured data.

### Features
- API Integration
- HTTP Requests
- JSON Parsing
- Structured Console Output

### Technologies Used
- Java
- HTTPURLConnection
- JSON Parsing

---

## Task 3 - Multithreaded Chat Application
A real-time client-server chat application using Java Sockets and Multithreading.

### Features
- Multiple Client Support
- Real-Time Messaging
- Multithreading
- Client-Server Architecture

### Technologies Used
- Java
- Socket Programming
- Multithreading

---

## Task 4 - AI-Based Recommendation System
A simple recommendation system that suggests content/products based on user preferences.

### Features
- User Preference Analysis
- Recommendation Logic
- Sample Dataset
- Console-Based Recommendations

### Technologies Used
- Java
- Recommendation Algorithms
